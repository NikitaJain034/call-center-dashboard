# Call Center Trends Dashboard
This repository contains a Power BI dashboard that provides insights into call center performance. The dashboard visualizes key metrics to help monitor and improve customer support operations.

## Overview
The dashboard includes the following KPIs:
- **Overall Calls Answered**: 4,054
- **Overall Calls Abandoned**: 946
- **Average Speed of Answer**: 68 seconds
- **Average Handle Time**: 225 seconds
- **Overall Customer Satisfaction**: 3.4 / 5
- **Total Calls Resolved**: 3,646

## Key Visuals
- **Monthly Trend of Calls**  
- **Calls by Agent**  
- **Calls by Time Slot (Morning, Noon, Evening)**  
- **Calls by Topic (e.g., Streaming, Technical Support, etc.)**  
- **Customer Satisfaction Breakdown**  
- **Call Volume by Day of the Week**

## Purpose
This dashboard was developed to:
- Track call center efficiency
- Identify patterns in customer issues
- Monitor agent performance
- Improve customer experience through data-driven decisions
